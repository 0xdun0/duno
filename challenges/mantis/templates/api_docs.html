EverSec Notification Builder API

RESTful API for automated notification rendering

Endpoints

POST /api/render

Render a notification with provided content and variables

Request

Content-Type: application/json

Body:

{ "template": "Hello {{ name }}, your account has been created.", "variables": { "name": "Alice" } }

Response

{ "success": true, "rendered": "Hello Alice, your account has been created.", "message": "Notification rendered successfully" }

Error Responses

400 Bad Request - Invalid input or missing data

{ "error": "Rendering error: ...", "hint": "Check your input syntax" }

500 Internal Server Error - Server error

{ "error": "Error: ..." }

Example cURL Request

curl -X POST http://localhost:4006/api/render \ -H "Content-Type: application/json" \ -d '{ "template": "Hello {{ name }}!", "variables": {"name": "Alice"} }'
