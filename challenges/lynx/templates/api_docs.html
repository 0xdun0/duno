EverSec Invoice Parser API

RESTful API for automated XML invoice processing

Endpoints

POST /api/parse

Parse XML invoice and extract data

Request

Content-Type: application/xml or text/xml

Body: XML invoice data

POST /api/parse HTTP/1.1 Host: localhost:4005 Content-Type: application/xml <?xml version="1.0" encoding="UTF-8"?> <invoice> <number>INV-2026-001</number> <date>2026-01-19</date> <customer>Acme Corporation</customer> <amount>1500.00</amount> <items> <item> <description>Security Audit</description> <price>1000.00</price> </item> </items> </invoice>

Response

{ "success": true, "invoice": { "number": "INV-2026-001", "date": "2026-01-19", "customer": "Acme Corporation", "amount": "1500.00", "items": [ { "description": "Security Audit", "price": "1000.00" } ] }, "raw_content": "...", "message": "Invoice parsed successfully" }
Note: The API supports standard XML DTD (Document Type Definition) declarations for extended XML processing.
Storage: Parsed invoice data is logged to a local directory for auditing. Application credentials are stored in an internal configuration file.

Error Responses

400 Bad Request - Invalid XML syntax or missing data

{ "error": "XML parsing error: ...", "hint": "Check your XML syntax and DTD declarations" }

500 Internal Server Error - Server processing error

{ "error": "Error: ..." }

XML Schema

Expected XML structure for invoices:

<invoice> <number>string</number> <date>string</date> <customer>string</customer> <amount>decimal</amount> <items> <item> <description>string</description> <price>decimal</price> </item> </items> </invoice>
