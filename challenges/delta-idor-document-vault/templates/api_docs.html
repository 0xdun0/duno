Document Vault API

REST API for programmatic access to the Document Vault. All endpoints require authentication via session cookie.

Endpoints

GET
/api/documents

Returns a list of all documents in the vault with their IDs, titles, and confidentiality status.

Response: 
{
  "documents": [
    {
      "id": 1042,
      "title": "Meeting Notes - Sprint Retrospective",
      "confidential": false
    },
    ...
  ],
  "total": 12
}
GET
/api/users/{id}

Returns profile information for a user account.

Response: 
{
  "id": 1,
  "username": "employee",
  "role": "employee",
  "department": "Engineering",
  "email": "jsmith@eversec.io",
  "internal_notes": "Standard user. Onboarded 2025-03-15."
}

Authentication

All API requests must include a valid session cookie. Obtain a session by logging in via the web interface.

Rate Limiting

API requests are limited to 100 requests per minute per session.
