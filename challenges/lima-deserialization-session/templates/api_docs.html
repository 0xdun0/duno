EverSec Session Manager API

RESTful API for session validation

Endpoints

POST /api/validate

Validate a session token

Request

Content-Type: application/json

Body:

{ "session": "gASVdQAAAAAAAACMCF9fbWFpbl9flIwLVXNlclNlc3Npb26Uk5QpgZR9lCiMCHVzZXJuYW1llIwEam9obpSMBHJvbGWUjAR1c2VylIwNYXV0aGVudGljYXRlZJSIjApjcmVhdGVkX2F0lIwZMjAyNi0wMS0xOVQyMDowMDowMC4wMDAwMDCUdWIu" }

Response

{ "valid": true, "username": "john", "role": "user", "authenticated": true }
Note: The session field should contain a valid session token.

Error Responses

400 Bad Request - Invalid or missing session data

{ "error": "Session data required" }

500 Internal Server Error - Validation error

{ "error": "Validation error: ..." }

Example cURL Request

curl -X POST http://localhost:4008/api/validate \ -H "Content-Type: application/json" \ -d '{ "session": "gASVdQAAAAAAAACMCF9fbWFpbl9f..." }'
