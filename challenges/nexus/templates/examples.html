Using the Validation API

You can validate a session token using the /api/validate endpoint:

curl -X POST http://localhost:4008/api/validate \ -H "Content-Type: application/json" \ -d '{ "session": "<your_session_token>" }'

A successful response returns session details:

{ "valid": true, "username": "john", "role": "user", "authenticated": true }

Role-Based Access

The application supports role-based access control. Sessions with the administrator role have elevated privileges and access to additional features.

Standard users are assigned the user role upon login. Only authorized personnel should have administrator access.
